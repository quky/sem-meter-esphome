## Pending annotated image

`programming-header-labeled.png` is intentionally pending. The supplied
photographs do not provide enough certainty to annotate every pin without
risking an incorrect orientation.

Before adding the file, verify the board directly against its PCB silk screen.
The final image must contain clear arrows pointing to:

- `3.3V`
- `GND`
- `TXD`
- `RXD`
- `IO0`
- `EN`

Do not guess a pin location, mirror the photograph, or infer a label hidden by
the installed header.
